Start/Stop — permanent disable 2 methods
Method 1 — Default off via Central Electronics Module 09 popular ▼
1
Connect VCDS, ignition ON, engine OFF
2
Select Control Module → 09 – Central Electronics
3
Click Security Access → enter code 20113 → click Do It!
4
Click Adaptation → in the channel box type 34 → click Read
5
Note the current value shown (e.g. 9)
6
To disable Start/Stop permanently: subtract 4 from the value → enter new value → click Do It!
7
To make it remember last state instead: add 32 to original value — better option if you sometimes want it on
8
Test: start car — Start/Stop button should now show OFF by default
💡 "Remember last state" (add 32) is arguably better — it stays off if you turned it off, on if you left it on. One-time setup, no button press needed.
⚠ If Channel 34 method doesn't work on your exact build, try Method 2 below via the gateway voltage trick.
Method 2 — Voltage threshold trick via Gateway Module 19 ▼
1
Select Control Module → 19 – Gateway
2
Click Adaptation → search for start-stop start voltage limit
3
Current value will be around 7.8V
4
Change to 12.1V → click Do It!
5
Start/Stop now thinks battery is always too low to activate and stays off permanently
ℹ This is a workaround, not a direct disable. Fully reversible — just set voltage back to 7.8 to restore. Works on builds where Channel 34 has no effect.

DSG gearbox (DQ381) — 1.5 DSG exclusive 2 procedures
DSG clutch adaptation reset Module 02 DSG only ▼
1
Gear in P, engine OFF, ignition ON, handbrake ON, foot brake pressed throughout
2
Check gearbox temperature in Measuring Values — must be above 15°C
3
Check for fault codes in Module 02 — clear any present before proceeding
4
Click Basic Settings – 04 → enter group 060 → click Go
5
Keep brake pressed — you'll hear clicking noises from the gearbox. This is normal.
6
Wait for status to show Finished correctly (about 60–90 seconds)
7
Start engine → cycle to D → drive gently for 15 minutes — no kickdown, no aggressive acceleration
8
Gearbox now relearns clutch pressure and bite points dynamically during this drive
💡 Do this whenever you notice DSG jerkiness in city traffic (common complaint). Takes 20 minutes total and often resolves the jerk completely. Safe to do every 20,000 km preventively.
⚠ Do NOT touch throttle or gear selector during the static phase (step 4–6). Abort = start over.
DSG live data — health monitoring Module 02 DSG only ▼
1
Select 02 – Auto Transmission → Advanced Measuring Values
2
Search and add these channels: clutch temperature 1, clutch temperature 2, TCU oil temp, clutch slip
3
Click Go and take the car for a drive — watch values live
4
Healthy: oil temp below 100°C normal driving, below 120°C spirited driving. Above 120°C = gearbox goes into safe mode
ℹ Pure monitoring — no changes made. Do this first before any DSG adaptation. Gives you baseline health data and confirms ACT / DSG behaviour on your specific car.
